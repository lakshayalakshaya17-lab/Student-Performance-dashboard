# Student Performance Dashboard

## 📊 Project Overview
An Excel dashboard created to analyze student performance and grades.

## 🛠️ Tools Used
- Microsoft Excel
- Excel Formulas
- Charts
- Conditional Formatting

## 📌 Features
- Total number of students
- Average marks
- Pass percentage
- Highest mark
- Student-wise performance
- Subject-wise average marks
- Grade distribution

## 📈 Dashboard
The dashboard provides a visual summary of student academic performance.
